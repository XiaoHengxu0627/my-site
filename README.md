# 作品集网站

极简风格的个人作品集站点（React + Vite + TypeScript），支持：

- 顶部导航（数字艺术 / 互动装置 / 视听演出 / 简介 / 联系）
- 作品列表页 → 作品详情页
- 中英双语切换（URL 查询参数 `?lang=zh|en`）
- 可配置内容：public/content 下的 JSON
- 可选内容管理后台：Decap CMS（/admin/index.html#/）

## 开发

```bash
npm install
npm run dev
```
